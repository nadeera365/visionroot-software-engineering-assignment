# Service Request Management System

VisionRoot software engineering internship assignment built with the MERN stack.

## Current progress

Project initialization and Git setup.

## Planned authentication

- Public registration is available to regular users only.
- Users and administrators are stored in separate MongoDB collections.
- Login provides User and Admin options.
- The backend verifies the selected account type and credentials.
- Administrator accounts will be created through a seed script.
- Real credentials will not be committed to Git.
